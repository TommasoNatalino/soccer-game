# ⚽ Calcio Arena

Un gioco di calcio completo giocabile nel browser — puro HTML, CSS e JavaScript, nessuna dipendenza.

## 🎮 Come giocare

Apri `index.html` nel tuo browser. Nessuna installazione richiesta.

## 🕹️ Controlli

| | Giocatore 1 | Giocatore 2 |
|---|---|---|
| **Muovi** | `W A S D` | `↑ ↓ ← →` |
| **Tiro / Tackle** | `SPAZIO` | `INVIO` |
| **Sprint** | `SHIFT SX` | `SHIFT DX` |
| **Pausa** | `ESC` | — |

## ✨ Funzionalità

- **Modalità 1 giocatore** — sfida la CPU con 3 livelli di difficoltà
- **Modalità 2 giocatori** — gioca in locale con un amico
- **5 vs 5** — portiere, difensori, centrocampisti, attaccanti con ruoli e AI distinte
- **Fisica realistica** — rimbalzi, collisioni giocatore-giocatore, frizione del pallone
- **Sprint** con stanchezza — gestisci l'energia dei tuoi giocatori
- **Tackle** — strappa il pallone agli avversari
- **Statistiche** — tiri e passaggi per ogni squadra
- **Durata partita** configurabile: 90s, 3 min, 5 min
- **Effetti particellari** su gol e azioni speciali

## 📁 Struttura

```
soccer-game/
├── index.html   # struttura e schermate
├── style.css    # grafica e animazioni

```

## 🚀 Deploy su GitHub Pages

1. Carica i file in un repository GitHub
2. Vai su **Settings → Pages**
3. Scegli il branch `main` come sorgente
4. Il gioco sarà disponibile su `https://tuousername.github.io/soccer-game/`
